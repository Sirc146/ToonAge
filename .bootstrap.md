- No obfuscation ever (Blizzard policy)
- No external price feeds (AH data from in-game API only)
- No SimC-level rotation sim (too complex; "good enough for leveling" approach)
- Python tools are dev-only, output static Lua files
- Party sync uses native C_ChatInfo addon messaging (no libraries)
- Update distribution via GitHub releases + PowerShell script (no desktop client)
- Guide architecture is expansion-agnostic by design
- All auto-features are opt-in with Shift-to-suppress convention

## LICENSING — READ BEFORE EXTRACTING FROM ANY REFERENCE ADDON
~190 addons are installed alongside ToonAge for study. Their *ideas* are fair game;
their *data* is not, unless the license says so. Verified 2026-07-25:

- **WoWPro** — `## X-License: Creative Commons Attribution-NonCommercial-NoDerivs 3.0`.
  **NoDerivs.** Its guides are a near-perfect schema match (`TWW_Hallowfall.lua` alone
  has 473 coords with quest IDs) and reformatting them into ToonAge's schema is exactly
  the derivative work that license forbids. Being free does not exempt us — ND is a
  separate restriction from NC. Path forward: ask the WoW-Pro Community
  (github.com/Ludovicus-Maior/WoW-Pro-Guides) for a written exception first.
- **APR** — `All Rights Reserved: You are free to fork and modify on GitHub, please ask
  us about anything else.` Extraction into ToonAge is "anything else." Ask first.
- **HandyNotes_\*** — no license file, no `X-License` field. Default copyright applies.
  Same "ask first" position, just undocumented.
- **Zygor / Dugi** — installed under `_retail_`. **Hard no.** Paid commercial products
  whose route data *is* the product. Behavioral benchmarks only, never their data.
- **Safe and already ours:** the Battle.net Game Data API via `Tools/` (licensed for
  exactly this), and `/taquestscan` in `DevHelpers.lua` for recording real coords in-game.
- **Not copyrightable:** UiMapIDs, quest IDs, item IDs, spell IDs. These are Blizzard
  game facts with one correct value — reading one off any addon is fine.
