## KEY GLOBALS & PATTERNS
- `ToonAge` (or `TA`) — main addon table
- `TA.modules` — module registry
- `TA.db` — SavedVariables (ToonAgeDB)
- `TA.charDB` — per-character data (TA.db.char["Name-Server"])
- `TA.charKey` — "Name-Server" string
- `TA.Data.Rotations`, `.StatWeights`, `.Talents`, `.Professions`, `.Zones`, `.Pets`
- `TA.Guides` — parsed guide registry (built by GuideParser from TA.GuideData)
- `TA.GuideData` — raw guide tables loaded from Data/Guides/*.lua
- `TA.Modern` — UIModern styling utilities
- `TA.Utils` (or `U`) — shared utilities (SafeNum, SafeCall, colors, formatting)
- Error handling: all module Init/OnEvent wrapped in pcall
- Frame pooling: UI.lua recycles frames to prevent memory inflation
- Layout modes: `db.useUnifiedUI` toggles Unified HUD vs Fragmented Windows

## GUIDE SCHEMA (v2)
```lua
{
    id, title, zone, minLevel, maxLevel, faction, nextGuide,
    steps = {
        { type, text, questID, coord={map,x,y}, objectiveIndex,
          range, spec, class, race, faction, minLevel, questItem,
          reward, noArrow, optional, precondition={questID, questComplete} }
    }
}
-- Step types: pickup, turnin, quest, travel, action, npc, text, item, accept
```

## SLASH COMMANDS
- `/ta` — toggle main panel
- `/ta gear|talents|rotation|prof|pets|weekly` — open specific tab
- `/ta tracker` — toggle floating quest tracker
- `/ta arrow` — toggle navigation arrow
- `/ta hud` — toggle NavHud overlay
- `/ta layout` — toggle Unified HUD ↔ Fragmented
- `/ta options` — settings panel
- `/ta toggle <module>` — enable/disable optional modules
- `/ta guides` — list loaded guides
- `/ta autoselect` — re-run guide auto-selection
- `/ta debug` — toggle debug mode
- `/ta reset` — wipe SavedVariables
