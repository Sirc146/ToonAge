# ToonAge — Competitor Feature Matrix
# Quick reference: what each addon does that ToonAge must match or beat.

## ZYGOR GUIDES ($15/month subscription)
- Leveling + Loremaster guides for ALL zones (Classic through Midnight)
- Dungeon walkthroughs with boss strategies per role (Tank/Healer/DPS)
- Gear Finder: BiS database + "which dungeon has most upgrades" suggestion
- Quest Reward Advisor: highlights best reward by stat weight, gold fallback
- Dailies + Reputation guide with renown milestone tracking
- Gold Guide: AH scanner + farming routes + crafting profit analysis + transmog runs
- Pets + Mounts collection guide with acquisition steps
- Titles + Achievements guide (hundreds of achievements covered)
- Quest NPC Icons: raid markers over NPCs (star=talk, skull=kill, square=click)
- Auto-dialogue selection for NPC conversations
- Map Preview: ant-trails inside instances (where waypoint arrows aren't allowed)
- Auto-accept/turn-in quests
- Auto-equip upgrades with notifications
- 3D Waypoint Arrow with portal/flight path/hearthstone routing
- Desktop client for installation/updates

## DUGI GUIDES (paid)
- Gear Advisor: scoring algorithm for auto-suggest/equip from bags + quest rewards
- Auto-Mount after combat
- Taxi/Flight Path routing to objectives
- Mailbox Finder
- Auto-equip best-in-slot from bags
- Waypoint arrow with TomTom-style navigation
- HereBeDragons map library integration

## HEKILI (free)
- SimulationCraft APL-based rotation prediction
- Multi-step lookahead (simulates future game state)
- Supports ALL DPS and Tank specs
- Imports APL strings from SimC/Raidbots
- Condition evaluation: buffs, debuffs, cooldowns, resources, target count
- NOT a guide addon — rotation ONLY

## APR / AZEROTH PILOT RELOADED (free)
- Speedrun-optimized leveling routes (used by world-record holders)
- Auto-accept quests
- Auto-turn-in quests
- Auto-gossip (NPC dialogue selection)
- Cutscene skipping
- Sojourner achievement skip (auto-detects when achievement is done)
- Safety checks on auto-features
- Minimal UI — just an arrow and step text

## WOW-PRO GUIDES (free)
- Community-written guides for all expansions
- Grail quest database integration (self-correcting quest data)
- TomTom integration for waypoints
- Party sync via RestedXP Multi addon
- Extensive formatting system for guide authors
- Open source, community maintained

## RESTEDXP (free addon, paid guides)
- Speedrun routes from world-record holders
- Multi-player sync (RestedXP Multi)
- Auto-accept/turn-in
- Class-specific route optimization
- Modern UI with progress tracking

## BTWTODO (free)
- Customizable per-character task grid (columns=chars, rows=tasks)
- Drag-and-drop task reordering
- Custom task creation (user-defined)
- Daily/Weekly/Midweek auto-reset timers
- Great Vault progress tracking
- Minimal resource usage

## PAWN (free)
- Tooltip stat weight scores on every item
- Green upgrade arrows on better items
- Custom stat weight import (paste from Raidbots/SimC)
- Compare UI for side-by-side item evaluation
- Per-spec weight profiles
- Armor type filtering (hides wrong-type items above level 27)

## FARMHUD (free)
- Transparent minimap overlay centered on screen
- Rotates with player facing
- Shows herb/ore/NPC tracking blips
- Click-through (doesn't block gameplay)
- Full minimap replacement while active
- Simple toggle on/off

---

## TOONAGE's UNIQUE MOAT (competitors don't have these combined)
1. Rotation helper integrated with guide system (no addon does both)
2. Endgame coaching (weekly/delves/alt tracker) in a guide addon
3. Stat-weight gear scoring built into the guide experience
4. NavHud (FarmHud equivalent) integrated — no separate addon needed
5. Zero dependencies — single folder install, no TomTom/Grail/Ace
6. Talent advisor with per-spec builds in a leveling addon
7. XP/hour tracking with cross-alt comparison
8. Role-based camera/CVar morphing
